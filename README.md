Entry for the [make.fun bounty "Everyday Wonder, Two Days to Find the Line"](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3): a single sentence, at most 200 characters, that makes a small everyday moment strange and new.

## The line

> The lift doors open on a stranger humming, and for one floor you're both inside the same song.

94 characters — one sentence, one line, nothing else. A lift ride turns into sharing a stranger's song for exactly one floor: ordinary, brief, and strange all at once. The surprise lands in a single read and stays grounded in something real — a lift, a stranger, a hummed tune.

## How it works

`main.ts` writes exactly that line to `/output/entry.txt`, validates it is 1–200 characters and a single line, then reads the file back to confirm it matches byte for byte.

Run it with Node 22:

```sh
node main.ts
```
